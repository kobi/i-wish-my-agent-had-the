# I wish my agent had the skill...

### `left-pad`

Pads a string on the left to a requested width, using spaces or a chosen fill character. The skill includes a dependency-free Python script for deterministic results.

```bash
npx skills add https://github.com/kobi/i-wish-my-agent-had-the --skill left-pad
```

See [left-pad/SKILL.md](left-pad/SKILL.md) for the skill instructions.
